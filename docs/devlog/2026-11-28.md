## 问题与解决

1. **`private sampleData() { }` 报「方法声明无效; 需要返回类型」**
   原因：构造器名小写 `s`，与类名 `SampleData` 不一致，Java 把它当成缺返回值的方法。
   解法：改为 `private SampleData()`。构造器名必须与类名逐字符一致，含大小写。

2. **`SampleData.all()` 内 `project.getId() == id` 报「无法解析符号 id」**
   原因：粘贴时把 `findById(int id)` 的方法体接到了 `all()` 的签名下面，`all()` 没有参数。
   解法：拆成两个方法，`all()` 只 `return Collections.unmodifiableList(PROJECTS);`，`findById` 单独声明 `int id` 形参。

3. **`MainActivity` 里 `DetailActivity` 报红 → 补上类之后 `R.layout.activity_detail`、`R.id.detail_root` 又报红**
   原因：符号解析是链式的，类、布局、字符串、Manifest 是同一组依赖，缺一个都红。
   解法：一次性补齐 DetailActivity + 布局 + 4 条字符串 + Manifest 声明，再统一编译。

4. **`git push` 报 `Failed to connect to github.com port 443 via 127.0.0.1`**
   原因：git 配置了代理 `http://127.0.0.1:7897`，但代理进程未启动。
   解法：先开代理再 push；应急可用 `git -c http.proxy= -c https.proxy= push` 临时绕过，不改全局配置。
