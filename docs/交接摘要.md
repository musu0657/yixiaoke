## 五、技术决策（已定，别反复推翻）

1. **语言 Java**：课纲写 Android + Java，不换 Kotlin。
2. **SQLite 三表，不加第四张表**：`study_record` 是"某天学了某项目"的事件表，`UNIQUE(project_id, checkin_date)` 天然去重；进度靠聚合，不存冗余字段。
3. **"web" 知识点**用 `WebView` + assets 本地 HTML「非遗小百科」，零服务器、离线可用。
4. **服务器端不做**：课纲没强制，本地 SQLite 已满足"数据库应用"；DAO 接口化 + WebView 作为未来接入点。
5. **功能范围**：必做 F1–F7；加分只做"打卡日历 + 搜索筛选"；其余进想法池（答辩作展望）。
6. **Git**：`main` 受保护，一律 `feature/fN-xxx` 分支 + PR + Squash merge；提交信息带阶段前缀 `[S1调研]` `[S3设计]` `[S5编码]` 等；每个功能至少 3 次提交（布局→逻辑→修问题）。
7. **构建**：AGP 9.3.0 + Gradle 9.5 + compileSdk 37 + minSdk 24，**已实际编译通过，不要主动降级**。遇到查不到原因的构建错误再考虑 AGP 8.7 + compileSdk 35。
8. **主题锁 Light**：`Theme.Material3.Light.NoActionBar`，避免深色模式毁掉国风配色。

### 已踩过的坑（别重复）

| 坑 | 现象 | 正确做法 |
|---|---|---|
| 样式名带点 | AAPT 报 `resource style/Yx not found`（点号是父样式语义） | 样式名用 `YxChip` 这种无点命名 |
| minSdk 24 的 SQLite | 只有 3.9.2，`INSERT ... ON CONFLICT DO UPDATE` 直接抛语法错误 | 用 `INSERT OR REPLACE`；UPSERT 需 API 29+ |
| 边到边 | 新 Activity 内容被状态栏遮挡 | 照抄 `MainActivity.applySystemBarInsets()` |
| 深色系统模式 | 状态栏图标白底白字看不见 | `setAppearanceLightStatusBars(true)` |
| 改错 gradle 文件 | 报 2 个红 | `namespace`/`applicationId` 只写在 `app/build.gradle.kts` |
| 无窗口模拟器 | "运行了没反应"，设备列表为空 | 别用 `-no-window`；AS 的 Device Manager 启动；卡住用 `adb devices` 查孤儿实例 |
| git 管道 | `git.exe 运行失败: pipe denied` | git 命令不要接 `| Select-Object` |
| 代理 | `Failed to connect to github.com port 443` | 先开 `127.0.0.1:7897` 代理再 push |
